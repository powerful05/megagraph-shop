# 3A Agent 界面演示图片

`public/demo-products/` 中的三张图片由内置 imagegen 生成，仅用于 3A/3B 顾客端界面预览：

| 演示来源 | 图片 | 画面 |
|---|---|---|
| 演示商家 A | `merchant-a-blue-shirt.jpg` | 浅蓝衬衫 |
| 演示商家 B | `merchant-b-ivory-knit.jpg` | 米白针织上衣 |
| 演示商家 C | `merchant-c-gray-cardigan.jpg` | 灰色开衫 |

这些来源不是已入驻的真实商家，图片也不证明材质、尺码、价格或库存。图片已接入顾客端演示对话，但没有写入商品库，也没有购买入口；正式推荐和购买只能读取商家确认、由后端校验的商品事实。

启用真实对话模型后，只有本地预览的公开商品目录为空时，后端才把这些图片的说明作为演示候选交给模型；页面仅显示模型选中且后端认可的演示图片 ID。真实模型回复不使生成图获得可售资格。
