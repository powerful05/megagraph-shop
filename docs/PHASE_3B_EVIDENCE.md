## 契约与校验

对话响应保留 `answer/products/demoProductIds`，新增 `advice` 与 `recommendationBasis`。`answer` 现在是服务端的简短结果说明；模型的自然语言建议与追问移至 `advice`。旧客户端仍能读取结果与商品，但不会自动展示新建议和依据；前后端需要配套发布。

每项推荐依据包含 `productId/productVersion/dataOrigin/facts/limitations`。事实条目为 `key/label/value`，最多六项；值与标签由 Java 从当前公开商品的已确认资料生成，不接受模型回传的属性值。限制包含资料原有说明、图片来源、成衣测量不保证人体合身，以及未列明性能不能确认的说明。未确认或缺失资料不生成属性事实，界面显示资料待补充，不把测试来源误称为已确认。

内部模型候选携带事实条目。模型选择商品，并返回 `evidenceReferences`：每项仅含 `productId` 与1到6个事实 key。响应必须是结构正确的 JSON；模型的普通文本、缺失引用字段、非整数商品标识或错误结构不再降级为可用聊天。该收紧替代初期模型接通文档中的普通文本兼容行为，错误仍通过既有脱敏503与显式重试处理。

服务端完成现时商品、预算、规格与版本检查后，再校验引用。引用必须属于实际返回商品、来自已确认资料、对应当前可选 SKU，不能重复或引用不存在的 key。错误商品、虚构防水属性、另一个 SKU 的规格或有事实却缺少引用时，撤回整段推荐、建议与卡片；不悄悄补造引用。EXACT 指代与 CHEAPER 服务端比较不调用回复模型，直接使用当前已确认条目，同样输出资料依据。

回复结构或候选引用失败时，应用层最多重新生成一次，使用相同候选并再次校验；只保留最终合法内容，不能用服务端猜测商品代替模型结果。第二次仍失败则503或撤回结果。上游鉴权、超时、限流、意图失败以及最终现时资料变化不自动重试。最多一次意图与两次回复调用，前端及评测超时从75秒调整到105秒；该预算不是延迟承诺，重新生成增加调用成本，脱敏日志记录其发生次数。

字段 key 为 `color/material/scenarios/fit/seasons/size-N/spec-N`；索引对应资料数组位置，并随资料版本核对，不是可跨版本复用的永久标识。服饰输出该 SKU 的成衣测量；通用实物仅输出该 SKU 的规格，不套用服饰字段。标题、副标题、图片或别的 SKU 不能代替属性依据。金额、库存与交易动作没有交给模型。

## 已知边界与下一步

可核验保证仅适用于服务端结果与结构化资料依据。`advice` 仍是模型生成的自然语言，即使单独标注、收紧提示并通过样本评测，也不是通用语义事实检查器；模型可能重复资料、暴露内部状态词或给出欠准确的用途/尺码建议。原始45题中，资料引用全部通过校验仍发生一次类别误选，证明引用正确不等于选品正确。

当前小目录验证不代表大目录性能、真实商家质量或用户满意度。意图提取与用途判断仍依赖模型；未声称每条新输入都正确。下一步优先处理已出现的预算改口漏选和错误范围说明，再继续多轮类别继承、必要性能与建议质量的重复评测，之后接入真实商家资料与小范围试用；数字购买、权益发放与预约仍须独立事实模型。

本轮改动保留于独立预览工作区，没有提交、合入 main 或推送。
