## 数据与隔离

基础 `supply-demo` 保持原有五件商品和49题问题集。额外启用 `supply-expanded` 后，增加60件较晚发布的测试商品，总计65件、65个SKU、两家测试商家、三个叶子类目。新增样本分为浅蓝衬衫、米白针织上衣、绿色A4文件袋、红色A5横线纸本，各15件，单价310至450元；原五件较早发布的低价样本必须全部在公开目录最新50件之外。

新增样本用于验证筛选和候选上限，并不是60款真实商品。图片与同色同品类基础样本共用，材质、规格、价格均为测试设定。商品通过既有草稿修改、确认、发布服务建立，发布事件同事务写入 Outbox。重复启动按测试商家与标题识别已有样本，不覆盖已存在商品修改，也不重复发布。

扩大目录使用独立本地H2文件 `apps/backend/var/db/guide-expanded`、独立媒体目录和 `GUIDE_EXPANDED_SESSION` Cookie，不修改基础预览数据库、购物袋或订单。H2结果不是MySQL验证。交易仍限实物；数字商品与服务继续测试需求识别和无交易供给边界，权益交付与预约未实现。

## 运行

在本预览 worktree 根目录启动后端，现有忽略的本机模型配置沿用，不在命令行填密钥：

```sh
GUIDE_TEST_SUPPLY=true GUIDE_EXPANDED_SUPPLY=true bash apps/backend/scripts/run-guide-local.sh
```

默认绑定本机8082。消费者独立预览使用不同编译目录，避免与3001基础预览共用开发产物：

```sh
NUXT_API_UPSTREAM=http://127.0.0.1:8082 NUXT_BUILD_DIR=var/nuxt-expanded pnpm --filter @megagraph/shopper-web exec nuxt dev --host 127.0.0.1 --port 3002
```

```sh
GUIDE_EVAL_BASE_URL=http://127.0.0.1:8082 node apps/backend/scripts/guide-evaluate.mjs --dataset expanded --out apps/backend/var/guide-evaluation-expanded.json
```

`--dataset` 只允许 `baseline` 或 `expanded`，默认基础目录。运行前核对完整SKU集合、商品数量、测试来源和确认状态；扩大目录还核对原五件均在最新50件之外。14题覆盖低价老商品检索、预算收紧、服饰改文具、电脑与纸本区分、用途澄清、缺失性能证明、缺失尺码、数字商品、服务和指定第二件。每轮核对公开商品版本、已确认依据、无演示回退；最终还核对限定SKU、预算、最多三件和指代一致。
